# Archived Arbitrum experiment

This directory contains the retired Arbitrum Sepolia adapter, contracts, browser-wallet bridge, historical integration notes and archived tests.

- It is not part of the active BOD product or Ethereum Foundation grant scope.
- It is not imported by the active Python package.
- Its archived tests are not collected by pytest or run by CI.
- No Arbitrum network is an active deployment target.
- The historical files are preserved for auditability and reproducibility, not maintained as supported integrations.

The active product is chain-independent evidence continuity with optional Ethereum L1/EAS witnessing. See `../../docs/ETHEREUM_INTEGRATION.md` and `../../docs/ROADMAP.md`.
