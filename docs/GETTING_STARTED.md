# BOD in 5 Minutes

This guide runs the local prototype. It does not deploy a blockchain or require a wallet, RPC endpoint, token, or paid service.

## 1. Install

Requirements: Python 3.11 or newer.

```bash
git clone https://github.com/BogdanXI/Blockchain-BOD.git
cd Blockchain-BOD
python -m pip install -e .
python -m pip install pytest pyyaml
```

## 2. Run the demonstration

```bash
bod demo
```

The command creates linked state transitions, verifies their lineage, and prints a machine-readable result. A successful demonstration only covers the behavior exercised by this local example.

## 3. Capture a repository snapshot

```bash
bod snapshot . --out snapshot.json
```

The snapshot root is derived from the ordered file paths, digests, and sizes. Treat the generated file as an artifact; do not commit private or sensitive project contents.

## 4. Verify evidence

```bash
bod verify envelope.json
bod verify chain.json --chain
python scripts/independent_verify.py chain.json --chain
```

Use the independent verifier as a separate implementation check. Follow the command's reported status rather than assuming that a file is valid because it was generated by BOD.

## 5. Run repository checks

```bash
python scripts/validate_public_surface.py
python -m pytest -q
```

The CI workflow runs the public-surface validation and test suite. Check the current [CI runs](https://github.com/BogdanXI/Blockchain-BOD/actions/workflows/ci.yml) for the latest result.

## What a successful result means

Verification checks the properties implemented by the verifier, including byte-level commitments and the applicable lineage rules. It does not prove that source statements are true, that evidence remains available, that an upstream build was honest, or that an external transition is canonical.
